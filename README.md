# MagStrain v151.5

Приём байтов Modbus продолжается через прерывание USART1. Ответ RS-485
формируется после завершения захвата. TIM3 останавливается на границе
расчётного окна, максимум через 0,91 мс после старта. Поздние фронты за
окном пропускаются. Фильтр уровня и подтверждение движения взяты из 151.4.

## Установка по Modbus

COM20, 19200, 8N1, адрес 1.

1. Закройте программу, которая использует COM20.
2. Запустите `MagStrain_COM20.exe` и дождитесь
   `Verified 51464 bytes, CRC32=FEBEB216`.
3. Сразу запустите `MagStrain_Install_COM20.exe`, введите латинскую
   заглавную `I` и нажмите Enter. Оставьте прибор включённым между этапами.
4. Дождитесь `Installed version: 151.5`. Чтение FC03 2420–2421 вернёт 151 и 5.

BIN содержит приложение для загрузчика. Адрес Flash 0x08003000.

## Проверка всплесков

1. Оставьте магнит в нуле и сохраните текущую настройку 6044.
2. Освободите COM20 и запустите `MagStrain_PulseTrace_30min_COM20.exe`.
   Утилита поддерживает 151.4 и 151.5. Для сравнения можно провести два
   прогона в одинаковых условиях, начиная с установленной 151.4.
3. Запись длится 30 минут. Для досрочного сохранения нажмите Ctrl+C.
   Файл `MagStrain_pulse_trace_*.csv` появится рядом с EXE.
4. При необходимости в конце прогона переместите магнит примерно на 1 мм
   и удержите, записав время перемещения.

Период запроса утилиты 200 мс. В CSV есть t1/t2 в тиках TIM3, уровень
в миллиметрах, статусы Modbus и номер запуска. Если на всплеске скачет t1,
нужно сравнить сигнал PB1 со стартом PB5 и проверить выход компаратора.
Если t1 стабилен во время всплеска уровня, проверяется расчёт после захвата.
Для обычного графика отдельно сравните частоту всплесков на одинаковом
интервале в 151.4 и 151.5.

Сборка ARM, тесты уровней и секундного буфера, имитация захвата и записи
CSV прошли. Проверка на приборе ещё нужна.

## Текущие измерения и секундная история

При кратком отказе захвата или расчёта уровня в стандартных регистрах сохраняется
последний достоверный снимок. Отсчёт идёт с момента публикации этого снимка.
Через 1000 мс без достоверных данных прошивка возвращает код недействительного
уровня при ближайшей попытке измерить уровень. 
Прибор фиксирует уровень один раз в секунду по внутреннему таймеру.
Хранятся 30 последних точек, включая секунды с недействительным уровнем.
Буфер расположен в RAM и начинается заново после отключения питания или сброса.
Чтение FC03 или FC04. Базовый адрес 0, слова float32 и uint32 младшим вперёд.

| Адрес | Данные |
|---|---|
| 1000–1001 | Текущий уровень, float32, мм |
| 6068 | Статус текущего снимка, uint16 |
| 6070–6071 | Номер последней секундной точки, uint32. Ноль до первой точки |
| 6072 | Число записей в буфере, 0–30 |
| 6073–6075 | Последняя точка. Уровень float32 в мм, затем статус uint16 |
| 6076–6078 | Предыдущая точка. Остальные точки идут в том же порядке |
| 6160–6162 | Тридцатая точка, самая старая |

Бит 0 статуса показывает, что уровень действителен. Бит 4 показывает, что
удерживается последнее достоверное значение. Когда бит 0 сброшен, уровень в
секундной истории передаётся кодом 0xFFFFFFFF. Для отображения новых точек
мастер использует номер точки, а при скачке номера читает блок 6070–6162
целиком и добавляет пропущенные записи от старых к новым.
При длительном перерыве связи сохраняются последние 30 секунд.

Для проверки буфера используйте `MagStrain_Seconds_COM20.exe`.
